# 胃バリウム透視シミュレーター



ブラウザで開くだけで使えます。インストールもログインも要りません。スマートフォンでも動きます。

---

診療放射線技師国家試験の上部消化管X線造影（胃バリウム検査）対策用の、ブラウザで動く 3D シミュレーターです。

`index.html` と `three.min.js` の 2 ファイルを同じ場所に置いて、`index.html` をブラウザで開くだけで動きます。three.js は CDN から読まずに同梱しているので、外部への通信は一切必要ありません（アプリ内ブラウザなど、外部スクリプトを読めない環境でも動きます）。
体位を変えると重力方向が変わり、硫酸バリウムとガスが胃内で入れ替わる様子と、どの壁面に二重造影像が
成立するかを可視化します。


## 4つのモード

- **学習** — 体位を「**起倒角**（立位 / 半立位 / 水平 / 頭低位）」×「**体軸の回転**（正面 / 第1斜位 / 第2斜位 / 右側臥位 / 左側臥位 / 腹臥位 / 腹臥位第1斜位 / 腹臥位第2斜位）」の2軸で組み立てます。4×8の組み合わせで、半立位第2斜位（＝シャツキー位）や背臥位第1斜位のような実際に使う体位がそのまま作れます。組み立てた体位の名称は上の表示に出て、よく知られた別名があれば添えられます。回転のアイコンは足側から見た体幹の断面で、三角が腹側・丸が棘突起、左右のR/Lは患者の右・左です。中間の角度はフリーモードで連続的に作れます。胃型は鉤状胃で固定です。
- **撮影手順** — 日本消化器がん検診学会「胃がん検診のための胃X線検査マニュアル 2025改訂第3版」表1-Ⅱ-1 の**基準撮影法Ⅰ（8体位）**と**基準撮影法Ⅱ（12体位）**を切り替えられます。ステップを選ぶとその体位に自動で動きます。順に再生もできます。体位名と順序はマニュアルの表そのままで、各ステップに添えた描出部位は一般的な教材の記載に合わせたものです。
- **フリー** — 操作卓のスティックで透視台の起倒角（縦方向, −30〜90°）と体軸の回転角（横方向）を、レバーで圧迫を操作します。手を離すと主要角度にスナップします。スティックには**国家試験に出た体位の目印**が置いてあり、そこへ持っていくと体位名・描出部位・出題（第○回 午前/午後 第○問）が出ます。
- **問題** — 診療放射線技師国家試験の実際の過去問から、胃・上部消化管に関する22問を収録。撮影技術だけでなく、胃の解剖・生理（主細胞、胃壁の層構造、ガストリン、胃液の作用など）も含みます。厚生労働省が公開している第65〜78回（2013〜2026年）の問題PDF・正答PDFを全てさらって抽出したもので、出典（第○回 午前/午後 第○問）を表示します。別冊の上部消化管造影写真3枚（背臥位二重造影・半立位第2斜位・腹臥位前壁）も同梱。「2つ選べ」に対応し、体位を問う設問では開いた瞬間にシミュレーターが同じ体位になります。**出題順は開くたびにシャッフル**されるので、並び順で答えを覚えてしまうことがありません。

図のある問題には**解剖の名札**を重ねられます。図の下の「解剖名」で表示を切り替え、答えると自動で出ます。拡大表示にも同じ名札が出ます。名札は `ann` フィールドに `[左からの%, 上からの%, 名前]` の並びで持たせています。**この注釈はリポジトリ側で付けたもので、試験問題には含まれません。**読み取りに自信がない構造には名前を付けていません。

厚生労働省が公開しているのは第65回（平成25年）以降で、それ以前の回はウェブ上にありません。

### 問題の貼り付け書式

厚生労働省の公表PDFからそのまま貼っても読めます（先頭に「第75回 午前」、各問を「問題 38 …」、選択肢を「1. …」で書いた形）。正答は別PDFなので `答え` の行だけ足してください。「2つ選べ」は `答え: 2,3` と書きます。

```
出典: 第○回 午前 第○問
問題: 設問の本文。
1: 選択肢
2: 選択肢
3: 選択肢
4: 選択肢
5: 選択肢
答え: 2
解説: 解説の文。
体位: 0,0
---
（2問目以降は --- で区切る）
```

`体位` は「起倒角,回転角」。書いておくと、その問題を開いたときシミュレーターがその体位になります（省略可）。「収録問題に戻す」で収録問題に戻せます。

### 斜位の定義について

**第1斜位は右前斜位（RAO）、第2斜位は左前斜位（LAO）** に相当する体軸の回し方です。台に寝ている患者では、同じ「第1斜位」でも背臥位と腹臥位で挙がる側が逆になります。

| | 第1斜位 | 第2斜位 |
|---|---|---|
| 背臥位（後壁をみる） | 右側挙上（回転角 45°） | 左側挙上（回転角 315°） |
| 腹臥位（前壁をみる） | 左側挙上（回転角 225°） | 右側挙上（回転角 135°） |

背臥位第1斜位（45°）と腹臥位第1斜位（225°）は 180° 離れた同じ斜位面で、後壁側から見るか前壁側から見るかの違いです。第2斜位（315°と135°）も同様の関係になります。

この対応は次の資料に拠っています。福島県保健衛生協会の受診者向け資料は「新・胃X線撮影法ガイドライン」を出典として、各体位を体の向きの言葉で説明しています。

- 公益財団法人 福島県保健衛生協会『胃透視検査 その1・その2』（2015年8月、「新・胃X線撮影法ガイドライン」より）
  https://www.fhk.or.jp/wp/wp-content/themes/fhk/img/cancer_health/itousikensa.pdf
  - 背臥位第1斜位 …「体全体を**左斜め**に向けます」
  - 背臥位第2斜位 …「体全体を**右斜め**に向けます」
  - 腹臥位第1斜位 …「うつぶせの状態から体を**左斜め**に向けます」

なお、この資料が挙げる基本8体位（背臥位正面／背臥位第1斜位／背臥位第2斜位／低頭位腹臥位／腹臥位第1斜位／右側臥位／背臥位第2斜位／立位第1斜位）は、日本消化器がん検診学会の基準撮影法Ⅰと一致します。

角度そのものはフリーモードで連続的に作れます。

## 装置の模型

透視台は台座の上で起倒し、天板・側レール・足台がいっしょに傾きます。患者は天板の上で体軸まわりに回ります。重力はつねに真下なので、台を倒せば背中側が低くなり、起こせば足側が低くなる — この関係がそのまま造影剤の流れになります。

管球と受像器は 3D には描いていません（視界をふさぐため）。X線束の向きは台の法線に固定されていて、「管球」視点に切り替えるとその方向から見た像になります。

骨格（脊柱と肋骨）は初期状態で表示しています。胃と椎体・肋骨の位置関係が分かるようにするためで、「表示と操作 → 骨格を3Dにも表示」で消せます。

患者の頭にはオレンジ色の**鼻**が付いています。鼻が向いているほうが腹側です。体位を変えたときにどちらが表でどちらが裏か、前壁・後壁のどちらが上になっているかをこれで判断できます。「表示と操作 → 鼻」で消せます（X線像・撮影したフィルムには写りません）。

バリウム量は 120 mL、ガス拡張は 60 % に固定です。

コンソールは幅を変えたり、画面から分離して 3D の上に浮かせたりできます。配置は保存されますが、ウィンドウが小さくなっても 3D が隠れないように読み込み時に必ず収まる大きさへ補正されます。幅 900px 以下では分離できません（戻すボタンが隠れてしまうため）。**Esc** で浮かせたコンソールを戻せます。3D を**ダブルクリック**すると視点が初期位置に戻ります。

## 初回の操作案内

はじめて開いたときだけ、3D の回し方を出すポップアップが出ます。`(pointer:coarse)` と画面幅で PC かスマートフォンかを判定し、ドラッグ／1 本指ドラッグ、ホイール／2 本指、ダブルクリック／ダブルタップを出し分けます。ほかの操作はボタンを押せば分かるので書いていません。閉じると記憶して次回からは出ません。題字の隣の「使い方」ボタンで開き直せます。

## スマートフォン

幅 900px 以下では 1 列に積み替わり、**3D が画面の上に貼り付いたまま**コンソールだけがスクロールします。体位を切り替えたときの胃の動きを、ボタンを押しながらそのまま見られます。

- 1 本指のドラッグで回転、2 本指のピンチで拡大縮小、ダブルタップで視点を戻す
- **問題タブだけは 3D を貼り付けません**。画面全体を使って、設問の図と5つの選択肢が 1 画面に収まります
- 横向きにすると左右 2 列（3D ＋ コンソール）に切り替わります
- PC（901px 以上）の見た目と操作はこれまでどおりです

## モデルの考え方

胃・食道・十二指腸を「軸に沿って断面が変化する管」としてモデル化し、体位から決まる重力方向に対して
1 次元の流体平衡を解いています。断面ごとの最下点の高さが流れの障壁になるため、瀑状胃のように胃底部が
後方に窪んだ形では「まず胃底部に溜まり、縁を越えてから胃体部へ流れ落ちる」挙動が自然に再現されます。

粘膜面へのバリウム付着は頂点ごとに保持され、一度バリウムに浸かった面はしばらく付着した状態が残ります。
「ガスに接した下側の壁が付着している」領域を二重造影域として色分けし、透視像では付着の厚みと接線方向の
壁を強調して、実際の二重造影像に近い見え方にしています。

透視像は管球を透視台に固定した幾何で描いています。体軸を回せばそのぶん斜位像になり、台を起こせばX線束も水平になります。
バリウムの厚み、粘膜への付着、接線方向の壁、軟部組織と骨の吸収差を重ねて濃度としており、実写ではありません。

数値も像もシミュレーションであり、診断や臨床判断に用いるものではありません。
