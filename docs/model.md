# シミュレーションの仕組み

数値も像もシミュレーションであり、診断や臨床判断に用いるものではありません。

## 胃の形

胃・食道・十二指腸を「軸に沿って断面が変化する管」として作っています。軸は制御点を通る曲線で、各断面は楕円（前後方向をやや扁平）です。胃型は鉤状胃で固定しています。

## バリウムとガスの分布

体位から重力の向きを決め、管の軸に沿った 1 次元の流体平衡を解いています。

- 断面ごとに、重力方向で見た最下点の高さを求める
- 隣り合う断面の間では、最下点の高いほうが流れの障壁になる
- バリウムは低いほうへ移り、障壁を越えられる分だけ先へ流れる

このため、胃底部が後方に窪んだ形では「まず胃底部に溜まり、縁を越えてから胃体部へ流れ落ちる」挙動が、特別な場合分けなしで現れます。各断面に溜まった量から水位を出し、水平な液面（ニボー）を描きます。

## 粘膜への付着と二重造影

- バリウムに浸かった粘膜面は、頂点ごとに「付着した」状態を記録する。付着はしばらく残る
- 「ガスに接しているが付着している壁」を二重造影域として色分けする
- 粘膜皺襞は断面の周方向・軸方向の模様として表面に重ねる

## 透視像

- 管球と受像器は透視台に固定している。体軸を回せばそのぶん斜位像になり、台を起こせば X 線束も水平になる
- バリウムの厚み、粘膜への付着、接線方向の壁、軟部組織と骨の吸収差を重ねて濃度にしている
- 「撮影」は同じ描画を 520 × 650 の画像に書き出し、R / L の表示を付けてフィルムにする

実写ではありません。

## 透視台と患者

透視台は台座の上で起倒し、天板・側レール・足台が一緒に傾きます。患者は天板の上で体軸まわりに回ります。重力は常に真下なので、台を倒せば背中側が低くなり、起こせば足側が低くなります。この関係がそのまま造影剤の流れになります。

台の回転軸は胃の高さに置いているため、台を起こすと足側が軸より大きく下がります。立位や頭低位で天板や足台が床にめり込まないよう、そのぶん床と台座を下げ、柱を伸ばして表示しています。患者と胃の位置、カメラは動きません。

管球と受像器は、視界をふさがないよう 3D には描いていません。

## 実装

- `index.html` 1 枚。HTML / CSS / JavaScript と、収録問題・図（Base64 の JPEG）を中に含む
- 3D 描画は three.js r128（`three.min.js` を同梱。CDN には依存しない）
- シェーダの精度指定は three.js に任せている（WebGL1 のフラグメントシェーダで highp が使えない端末があるため）
- 3D が描けないときは理由を画面に出す
