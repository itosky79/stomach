# 体位の定義と撮影手順

## 角度の決め方

アプリ内の体位は、**透視台の起倒角**と**体軸の回転角**の 2 つで決まります。

| 起倒角 | 名前 |
|---|---|
| 90° | 立位 |
| 45° | 半立位（半臥位） |
| 0° | 水平（背臥位・腹臥位・側臥位） |
| −30° | 頭低位 |

体軸の回転角は、仰向け（背臥位正面）を 0° として、右側が挙がる向きを正にとっています。

| 回転角 | 名前 | 挙がる側 |
|---|---|---|
| 0° | 正面（背臥位） | — |
| 45° | 第1斜位 | 右側 |
| 90° | 左側臥位 | 右側（左が下） |
| 135° | 腹臥位第2斜位 | 右側 |
| 180° | 腹臥位 | — |
| 225° | 腹臥位第1斜位 | 左側 |
| 270° | 右側臥位 | 左側（右が下） |
| 315° | 第2斜位 | 左側 |

## 第1斜位・第2斜位

**第1斜位は右前斜位（RAO）、第2斜位は左前斜位（LAO）** に相当する回し方です。台に寝ている患者では、同じ「第1斜位」でも背臥位と腹臥位で挙がる側が逆になります。

| | 第1斜位 | 第2斜位 |
|---|---|---|
| 背臥位（後壁をみる） | 右側挙上（45°） | 左側挙上（315°） |
| 腹臥位（前壁をみる） | 左側挙上（225°） | 右側挙上（135°） |

背臥位第1斜位（45°）と腹臥位第1斜位（225°）は 180° 離れた同じ斜位面で、後壁側から見るか前壁側から見るかの違いです。第2斜位（315° と 135°）も同じ関係です。

根拠：福島県保健衛生協会『胃透視検査 その1・その2』（「新・胃X線撮影法ガイドライン」より）の、受診者向けの体の向きの説明。

- 背臥位第1斜位 …「体全体を**左斜め**に向けます」
- 背臥位第2斜位 …「体全体を**右斜め**に向けます」
- 腹臥位第1斜位 …「うつぶせの状態から体を**左斜め**に向けます」

仰向けで左斜めを向けば右側が挙がり（45°）、うつぶせで左斜めを向けば左側が挙がる（225°）。上の表と一致します。

## 撮影手順（基準撮影法）

日本消化器がん検診学会『胃がん検診のための胃X線検査マニュアル 2025 改訂第3版』表 1-Ⅱ-1 の順序です。体位名と順序は表のとおりで、描出部位は一般的な教材の記載に合わせて添えています。

### 基準撮影法Ⅰ（8 体位 8 曝射。対策型検診）

| | 体位 | 起倒角 / 回転角 | 描出部位 |
|---|---|---|---|
| ① | 背臥位二重造影正面位 | 0° / 0° | 胃体部後壁 |
| ② | 背臥位二重造影第1斜位 | 0° / 45° | 胃角部〜前庭部後壁 |
| ③ | 背臥位二重造影第2斜位（頭低位） | −30° / 315° | 穹窿部・噴門部 |
| ④ | 腹臥位二重造影正面位（頭低位） | −30° / 180° | 前庭部前壁 |
| ⑤ | 腹臥位二重造影第1斜位（半臥位） | 45° / 225° | 胃体上部前壁 |
| ⑥ | 右側臥位二重造影 | 0° / 270° | 胃上部・十二指腸 |
| ⑦ | 背臥位二重造影第2斜位 | 0° / 315° | 胃体上部後壁（ふりわけ） |
| ⑧ | 立位二重造影第1斜位 | 90° / 45° | 胃上部・噴門部 |

| | 体位 | 起倒角 / 回転角 | 描出部位 |
|---|---|---|---|
| ① | 立位二重造影第1斜位（食道上・下部） | 90° / 45° | 食道上部・下部 |
| ② | 背臥位二重造影正面位 | 0° / 0° | 胃体部後壁 |
| ③ | 背臥位二重造影第1斜位 | 0° / 45° | 胃角部〜前庭部後壁 |
| ④ | 背臥位二重造影第2斜位（頭低位） | −30° / 315° | 穹窿部・噴門部 |
| ⑤ | 腹臥位二重造影正面位（頭低位） | −30° / 180° | 前庭部前壁 |
| ⑥ | 腹臥位二重造影第2斜位（頭低位） | −30° / 135° | 胃体部前壁 |
| ⑦ | 腹臥位二重造影第1斜位（半臥位） | 45° / 225° | 胃体上部前壁 |
| ⑧ | 右側臥位二重造影 | 0° / 270° | 胃上部・十二指腸 |
| ⑨ | 半臥位二重造影第2斜位 | 45° / 315° | 胃体上部・噴門部 |
| ⑩ | 背臥位二重造影第2斜位 | 0° / 315° | 胃体上部後壁（ふりわけ） |

| ⑫ | 立位圧迫（体部・胃角部・前庭部・幽門部） | 90° / 0° | 圧迫 |

福島県保健衛生協会の資料が挙げる基本 8 体位（背臥位正面／背臥位第1斜位／背臥位第2斜位／低頭位腹臥位／腹臥位第1斜位／右側臥位／背臥位第2斜位／立位第1斜位）は、基準撮影法Ⅰと一致します。

## フリーモードの目印

描出部位は日本人間ドック・予防医療学会『上部消化管エックス線健診判定マニュアル』の標的部位に拠ります。出題番号は、このリポジトリに収録して正答値表と照合した問題だけを載せています。

| 体位 | 起倒角 / 回転角 | 描出部位 | 出題 |
|---|---|---|---|
| 立位正面 | 90° / 0° | 立位圧迫で体部・胃角部・幽門前庭部・幽門部。隆起や陥凹の形の観察に向く | 第72回 午前 第90問 |
| 半立位第2斜位（シャツキー位） | 45° / 315° | 噴門部から体上部の後壁。基準撮影法Ⅱ⑨ | 第74回 午後 第93問、第71回 午前 第89問 |
| 背臥位正面 | 0° / 0° | 体部から幽門前部の後壁。二重造影の基本 | 第76回 午後 第85問、第73回 午前 第83問 |
| 背臥位第1斜位 | 0° / 45° | 体部の大弯寄り後壁から幽門前部の小弯寄り後壁。十二指腸球部も | 第75回 午前 第91問 |
| 腹臥位正面 | 0° / 180° | 体中部から幽門前部の前壁 | 第65回 午後 第81問 |
| 右側臥位 | 0° / 270° | 噴門部小弯を中心とした前後壁。バリウムが十二指腸へ流れる | 第71回 午前 第89問 |
| 左側臥位 | 0° / 90° | 胃底部が低くなる。腹部単純では遊離ガスの検出に使う | 第70回 午後 第88問 |
| 腹臥位第1斜位（半臥位） | 45° / 225° | 噴門部から胃上部（体上部と穹窿部）の前壁。基準撮影法Ⅰ⑤ | （基準撮影法の体位） |
| 腹臥位第2斜位（頭低位） | −30° / 135° | 体中部の大弯寄り前壁から幽門前部の小弯寄り前壁。基準撮影法Ⅱ⑥ | （基準撮影法の体位） |

Radiological Site には第60〜64回の出題も挙がっていますが、厚生労働省がウェブで公開しているのは第65回以降のため確認できず、載せていません。
