# 機能と操作

## 画面の構成

左が 3D（透視台・患者・胃）と透視像、右がコンソールです。3D の上のボタンで表示を切り替えます。

| ボタン | 内容 |
|---|---|
| 3D | 3D だけ |
| 3D + 透視 | 3D と、右下にその瞬間のシミュレーション透視像（初期状態） |
| X線像 | 透視像を大きく |
| 撮影 | その時点の透視像を、画面下の「撮影したフィルム」に 1 枚追加する。クリックで拡大 |

## 3D の操作

| | PC | スマートフォン |
|---|---|---|
| 回転 | ドラッグ | 1 本指でドラッグ |
| 拡大縮小 | ホイール | 2 本指でピンチ |
| 視点を戻す | ダブルクリック | ダブルタップ |

はじめて開いたときだけ、この回し方を出すポップアップが出ます（PC かスマートフォンかで中身が変わる）。題字の隣の「使い方」でいつでも開き直せます。

## 4 つのモード

### 学習

体位を「起倒角」と「体軸の回転」の 2 軸で組み立てます（4 × 8 ＝ 32 通り）。上の表示に組み立てた体位の名前が出て、よく知られた別名があれば添えます（例：半立位第2斜位 → シャツキー位）。

- 起倒角：立位 / 半立位 / 水平 / 頭低位
- 体軸の回転：正面 / 第1斜位 / 第2斜位 / 右側臥位 / 左側臥位 / 腹臥位 / 腹臥位第1斜位 / 腹臥位第2斜位

回転のアイコンは足側から見た体幹の断面で、三角が腹側、丸が棘突起、左右の R / L が患者の右・左です。角度の定義は [positions.md](positions.md) を参照。

### 手順

日本消化器がん検診学会の**基準撮影法Ⅰ（8 体位）**と**基準撮影法Ⅱ（12 体位）**を切り替えられます。ステップを選ぶとその体位へ動きます。「順に再生」で自動で進みます。

### フリー

操作卓のスティックで起倒角（縦）と体軸の回転（横）を連続的に動かし、右のレバーで圧迫します。手を離すと主要な角度に寄ります。

スティック上の小さな丸は**国家試験に出た体位・基準撮影法の体位の目印**です。そこへ合わせると、体位名・描出部位・出題番号が下に出ます。

### 問題

診療放射線技師国家試験の実際の過去問 22 問（[一覧](questions.md)）。

- 出典（第○回 午前/午後 第○問）を表示
- 出題順は開くたびにシャッフル。選択肢の順番は国試のまま
- 「2 つ選べ」に対応
- 体位を問う設問では、開いた時点でシミュレーターが同じ体位になる
- 図のある問題は図と選択肢を同時に表示。コンソールが広いときは左右に並ぶ
- 図には**解剖の名札**を重ねられる（「解剖名」ボタン。答えると自動で出る。拡大表示にも出る）。名札はこのアプリで付けた注釈で、試験問題には含まれない
- 「問題を入れ替える」で、自分で用意した問題を貼り付けて使える（書式は下記）

## 表示と操作（コンソール下部の折りたたみ）

| 項目 | 初期値 | 内容 |
|---|---|---|
| ラベル | 主要 | 胃の部位名ラベルの量（なし / 主要 / 詳細） |
| 骨格を 3D にも表示 | オン | 脊柱と肋骨を 3D に出す。胃との位置関係を見るため |
| 鼻（腹側の目印） | オン | 頭のオレンジの鼻。向いている側が腹側。X 線像には写らない |
| 幽門を開く | オフ | バリウムを十二指腸へ流す |
| 飲み直す | — | バリウムを入れ直す |
| フィルム消去 | — | 撮影したフィルムを消す |

バリウム量は 120 mL、ガス拡張は 60 % で固定です。

## コンソールの配置

- 3D との境目をドラッグすると幅を変えられる
- 「分離」で 3D の上に浮かせ、ドラッグで移動・右下の角で大きさ変更。**Esc** で戻る
- 配置はブラウザに保存される。ウィンドウが小さくなっても 3D が隠れないよう、読み込み時に収まる大きさへ補正する
- 幅 900px 以下では分離できない（戻すボタンが隠れてしまうため）

## スマートフォン

- 幅 900px 以下では 1 列になり、**3D が画面上部に貼り付いたまま**コンソールだけがスクロールする
- 問題タブだけは 3D を貼り付けず、設問の図と選択肢を 1 画面に収める
- 横向きでは左右 2 列

## 問題の貼り付け書式

```
出典: 第○回 午前 第○問
問題: 設問の本文。
1: 選択肢
2: 選択肢
3: 選択肢
4: 選択肢
5: 選択肢
答え: 2
解説: 解説の文。
体位: 0,0
---
（2 問目以降は --- で区切る）
```

- 「2 つ選べ」は `答え: 2,3`
- `体位` は「起倒角,回転角」。書くと、その問題を開いたときにその体位になる（省略可）
- 厚生労働省の公表 PDF からそのまま貼っても読める（先頭に「第75回 午前」、各問を「問題 38 …」、選択肢を「1. …」とした形）。正答は別 PDF なので `答え` の行だけ足す
- 「収録問題に戻す」で元の 22 問に戻る
