# 胃X線検査（バリウム検査）の基本

シミュレーターを作るうえで知っておくべき、検査の基本の手順と考え方をまとめた（2026-10-27 調べ）。各項目の終わりに出典の記号を付けた。記号は最後の「出典」の表にある。

## 1. 何を見ているのか

- 胃の壁に**薄く付いたバリウムの膜**を、発泡剤のガスで膨らませた胃の中の空気を背景にして写す。これを二重造影という。たまったバリウムを見ているのではない［B］
- たまったバリウムは、付いた膜を隠すもの。撮りたい壁から、たまりをどかすのが体位変換の目的
- 背臥位（あお向け）では、背中側の壁（後壁）が下になり、そこに付いた膜が写る。前壁は写りにくい。そのために腹臥位（うつぶせ）の撮影がある［B］［F］

## 2. 使う薬と量（基準撮影法）

| もの | 量 | 出典 |
|---|---|---|
| バリウム | 濃さ 180〜220W/V%（200 以上がよい）、量 120〜150mL（150mL 前後がよい） | ［A］ |
| 発泡剤 | 5.0g が基本。バリウムかその 2 倍までに薄めたもの 20mL 程度で飲む。水だけで飲むのはすすめない | ［A］ |
| 胃の動きを止める薬（鎮痙剤） | バリウムと発泡剤だけで胃の動きは数分止まるので、必ずしも使わなくてよい | ［A］ |

- 発泡剤の添付文書では、炭酸ガス約 100〜400mL に当たる量を、胃の大きさや体位に合わせて飲ませる［E］
- 小さい胃（牛角胃など）に一度に多く飲ませると膨らみすぎる、という報告がある［E］
- 胃の動きが止まっている数分の間に、主な撮影を手早く終えるのがこつ。**体位変換を何度もしすぎると、バリウムが付きすぎて細かい病変が見えにくくなる**［C］

## 3. 撮影の順番（基準撮影法）

基準撮影法Ⅰ（対策型検診、8 体位）と基準撮影法Ⅱ（人間ドックなど、12 体位）がある［A］。

| 順 | 基準撮影法Ⅰ | 基準撮影法Ⅱ |
|---|---|---|
| | | 立位・第1斜位（食道） |
| 1 | 背臥位・正面位 | 背臥位・正面位 |
| 2 | 背臥位・第1斜位 | 背臥位・第1斜位 |
| 3 | 背臥位・第2斜位（頭低位） | 背臥位・第2斜位（頭低位） |
| 4 | 腹臥位・正面位（頭低位） | 腹臥位・正面位（頭低位） |
| | | 腹臥位・第2斜位（頭低位） |
| 5 | 腹臥位・第1斜位（半臥位） | 腹臥位・第1斜位（半臥位） |
| 6 | 右側臥位 | 右側臥位 |
| | | 半臥位・第2斜位 |
| 7 | 背臥位・第2斜位 | 背臥位・第2斜位 |
| 8 | 立位・第1斜位 | 立位・第1斜位 |
| | | 立位・圧迫（体部・胃角部・前庭部・幽門部） |

- 2025 年版で「背臥位の正面像（胃の正面像）」と「立位の正面像」がなくなった。胃の正面像を得るために体位を細かく合わせることは求めない［A］
- **撮影の順番と、体位と体位の間の動かし方まで含めて守るのが基準撮影法**。画像がそろえば順番はどうでもよい、ではない［C］
- 被ばくの目安：基準撮影法Ⅰは 39mGy・透視 2 分 30 秒、Ⅱは 55mGy・透視 4 分［A］

## 4. 体位ごとのねらいとこつ

勉強会の資料［C］から。学会のマニュアルの書籍版で確かめること。

| 体位 | 見る場所 | 台の角度 | こつ |
|---|---|---|---|
| 背臥位・正面位 | 幽門〜体部の後壁 | 水平。広く出すために少し頭低位もよい | 下垂胃ではバリウムがたまるので頭を少し下げる。少しの傾きでも声かけをする |
| 背臥位・第1斜位 | 幽門の小弯〜体部の大弯の後壁 | 水平 | 撮る前に水平で右回りに 1 回転。十二指腸や背骨と重ならないようにする |
| 背臥位・第2斜位（頭低位） | 幽門の大弯〜体部の小弯の後壁 | 頭低位 | 撮る前に水平で右回りに 1 回転。幽門部にバリウムを残さない。十二指腸や背骨と重ならないようにする |
| 腹臥位・正面位（頭低位） | 体部〜幽門部の前壁 | 頭低位 −30〜−45° | お腹の下に圧迫用のふとんを入れる。どの人でも −45° まで下げればよいわけではない |
| 腹臥位・第1斜位（半臥位） | 胃の上部の前壁〜小弯 | 半臥位 20〜30° | 息を吐いて撮る。起こしすぎるとバリウムが流れ落ちて付きが悪くなる（目安 30° 以下） |
| 右側臥位 | 胃の上部の前壁・後壁 | 水平〜15° | 息を吐いて撮る |
| 背臥位・第2斜位（振り分け） | 体部の小弯〜後壁 | 水平〜30° | お腹で息をさせてバリウムの流れを調整しながら透視で見る。台の角度でバリウムの流れる場所が変わる |
| 立位・第1斜位 | 胃の上部の大弯 | 立位。なるべく強い第1斜位 | バリウムが流れ落ちたところを撮る |
| 立位・圧迫 | 体部・胃角部・前庭部・幽門部 | 立位 | 圧迫することを説明する。痛ければすぐ言ってもらう。無理に押さない。痛みが強いとき、バリウムが少なすぎるときは撮らない |

前壁の撮影（腹臥位・頭低位）について、古い文献には次の手順が書かれている［F］。
- お腹の下に小さく平らなふとんを入れ、その下の端をへそのあたりに置く
- 軽い半臥位から強い腹臥位・第2斜位にして、空気が幽門部に入ったのを確かめてから頭を下げる
- 前壁が二重造影で出たところで止める。頭の下げ方は 30〜45°

## 5. 基準撮影法でも見えない場所ができる理由

勉強会の資料［C］から。
- 胃はやわらかく、体位ごとにねじれる
- 画面に対して横向きになる壁（例：背臥位・正面位の大弯や小弯）は、正面から見られない
- 腸が重なる
- バリウムが残る

## 6. 安全

- 検査を受けてはいけない人：消化管がつまっている・穴があいている疑いのある人、妊娠中の人など［A］
- 受けないほうがよい人：過去にバリウムを誤って気管に飲み込んで（誤嚥して）検査が中止になった人、寝返りや立ち上がりにいつも手助けが要る人など［A］
- 検査中：寝台を動かすときに声をかける。肩当てと手すりがちゃんと付いているか目で見る［A］
- 2015 年に、検診車の撮影台から受診者が落ちて亡くなる事故があった。頭を下げる撮影の前に説明し、肩当てと手すりの使い方を徹底する［D］
- 検査後：バリウムが出ないと腸がつまったり穴があいたりするので、早めに水と食事をとり、下剤を飲むように伝える［A］

## 7. シミュレーターとのずれ（今わかっているもの）

| 項目 | 実際 | 今のシミュレーター |
|---|---|---|
| 見ているもの | 壁に付いた膜 | 付き方は計算していない。最初に壁全体に付けて、時間で減らしているだけ |
| ローリング | 撮る前に水平で右回り 1 回転、など | ない |
| 腹臥位・第1斜位（半臥位）の角度 | 20〜30°（目安 30° 以下）［C］、半臥位 = 30° 未満［G］ | 25°（2026-10-27 に 45° から直した） |
| 腹臥位・頭低位の角度 | −30〜−45°［C］［F］ | −30° |
| 腹臥位の圧迫ふとん | 使う | ない |
| 体位変換のしすぎ | バリウムが付きすぎて悪くなる | 表現できない |
| 見えない場所 | ねじれ、横向きの壁、腸の重なり、残ったバリウム | 胃の形は変わらない。横向きの壁と重なりは描出率で数えていない |
| 発泡剤 | ガス 100〜400mL。小さい胃では膨らみすぎに注意 | ガスの量と胃の膨らみ方の関係に根拠がない |

参考：シミュレーターで腹臥位・正面位の頭低位を 0〜−45° まで振ったところ、前庭部の前壁が出始めるのは −20〜−25° からだった（手で作った 4 つの胃の形、`results/sweep_4types_20261026.csv`）。資料の −30〜−45°［C］［F］と矛盾しない。ただし胃の形に出典がないので、根拠としては弱い。
